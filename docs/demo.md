# 互動島嶼 Demo

GitHub Pages 展示的是前端互動原型。它不提供真實 AI 連線，也不連接任何帳號、CLI、API 或本機檔案。

## 建議展示流程

1. 開啟「我的島嶼辦公室」，先看完整島嶼、部門子島、群組建築與漫步中的角色。
2. 將游標移到部門木牌，或點一下木牌，查看該部門的群組清單；點群組建築可開啟群組對話。
3. 點選島上的角色，查看角色私聊。關閉對話遮罩後會回到原本的辦公室地圖。
4. 在左側點「建立群組」，選擇部門與成員；新群組會成為目前島上的建築。
5. 在上方切換器新增另一個島嶼辦公室，查看不同景觀與獨立的島嶼空間。
6. 在對話框輸入一段測試訊息。頁面會產生明確標為示範的模擬回覆，供展示互動流程。

## 示範資料與儲存

- 初始角色、群組和聊天內容是通用預置展示資料，不含客戶、合作廠商或外包專案內容，也不代表已從 Hermes 或 Grok 匯入。
- 新增的辦公室、群組、木牌位置、景觀選擇與對話保存在該瀏覽器的本機儲存空間。
- 清除網站資料或換一個瀏覽器後，這些操作結果不會跟著搬移。
- GitHub Pages 展示不支援 Hermes、Grok、Claude、Codex OAuth、API Key、CLI 登入、工作階段同步或本機歷史匯入。

若要用真實來源交談，請參考[本機私用與真實連線](local-use.md)。
