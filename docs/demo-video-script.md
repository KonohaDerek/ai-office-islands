# 對話 Demo 影片拍攝腳本

## 已錄製影片

[播放／下載 AI Office 公開展示影片（M4V，1080p）](media/ai-office-demo.m4v)

影片以乾淨的公開展示資料重新錄製，包含島嶼總覽、群組對話、示範回覆、成員清單及返回地圖。畫面不包含客戶、合作廠商或外包專案資料；對話是模擬內容，沒有連接 Hermes、Grok、Claude、Codex 或其他外部 AI。

## 拍攝腳本

建議成片長度：約 90 秒。以下腳本可供後續配音或重拍使用。不要在錄影中輸入 API Key、顯示私人工作階段或暗示示範回覆來自真實 AI。

| 時間 | 畫面與操作 | 旁白／字幕 |
| --- | --- | --- |
| 0–10 秒 | 全島畫面，慢慢移動游標，呈現海島、建築與角色。 | 「這是 AI Office，一座用島嶼呈現 bot、部門與群組的虛擬辦公室。」 |
| 10–23 秒 | 將游標移到影音部木牌，點開群組清單。 | 「部門以子島和木牌呈現；每個群組都有自己的建築。」 |
| 23–38 秒 | 點一棟群組建築，展示群組對話遮罩與成員頁籤。 | 「點選群組，可以查看對話和成員；關閉後回到同一座島。」 |
| 38–52 秒 | 輸入「幫我規劃一支海島旅遊影片」，送出並等候示範回覆。 | 「這是公開互動 demo，回覆是預置的模擬內容，不會呼叫外部 AI。」 |
| 52–63 秒 | 關閉群組對話，再點一位角色，展示角色私聊。 | 「也可以直接和島上的單一角色互動。」 |
| 63–75 秒 | 建立群組，選擇部門和成員，回到地圖查看新建築。 | 「建立群組後，建築會加入目前島嶼，方便逐步擴展版圖。」 |
| 75–85 秒 | 新增另一間島嶼辦公室並切換景觀。 | 「只有新增島嶼辦公室才會建立新島；不同辦公室可以使用不同景觀。」 |
| 85–90 秒 | 停在 GitHub Pages 模擬對話標示，收尾。 | 「公開版用於展示。Hermes、Grok、Claude 和 Codex 的真實連線請在本機私用版設定。」 |

## 錄製前

- 使用乾淨的瀏覽器展示資料；避免個人姓名、歷史訊息或自訂頭像洩漏。
- 確認畫面顯示「GitHub Pages · 模擬對話」。
- 螢幕錄影建議 1920×1080、30 fps；游標移動放慢，對話文字保持可讀。
- 影片成品放在 `docs/media/`；更新後同步修改上方連結與 README。
